A modern, secure, and professional password generator web application with advanced security features and elegant UI design.

## Features ✨

- 🔐 Generate strong random passwords with customizable length
- 📋 One-click copy to clipboard functionality
- 📊 Visual password strength indicator with entropy calculation
- 🎨 Modern glassmorphism UI design
- 🌈 Animated gradient background
- 📱 Responsive design for all screen sizes
- 🛠 Configurable character sets (uppercase, lowercase, numbers, symbols)
- 🔊 User feedback notifications
- 📈 Password entropy calculation and security rating
- 🎚 CSS custom properties for easy theming
