# 💰 Cash Calculator 

A dynamic web application that calculates cash differences and displays breakdowns in both numerical and written formats, with denomination breakdowns. Features real-time calculations and error handling.

## ✨ Features

- **Dual Input System** 
  - Bill Amount entry
  - Cash Given input
- **Smart Calculations**
  - Difference amount display
  - Written amount conversion
  - Note denomination breakdown
- **Error Handling**
  - Input validation
  - Error modal popups
  - Negative value prevention
- **Interactive UI**
  - Hover effects
  - Smooth animations
  - Modal transitions
- **Responsive Design**
  - Flexbox layout
  - Mobile-friendly structure
  - Adaptive container sizing

## 🖥️ Usage

1. Enter Bill Amount
2. Enter Cash Given
3. Click "Calculate"
4. View:
   - Numerical difference
   - Amount in words
   - Currency note breakdown
   - Error messages for invalid inputs
